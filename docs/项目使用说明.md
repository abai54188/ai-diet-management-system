# AI 智能饮食管理系统 — 项目使用说明

本篇面向「普通使用者」与「开发者」，介绍从环境准备、安装启动到各功能使用的完整流程。

---

## 1. 需要准备的环境（必看）

### 1.1 运行环境

| 软件 | 版本 | 是否必需 | 下载地址 |

## 2. 安装与启动

### 2.1 方式 A：直接运行（普通使用者，最快）

1. 安装 **Java 17**（见 1.1）。
2. 获取打包产物 `diet-backend-1.0.0.jar`（放在 `start.bat` 同目录，或 `backend/target/` 下）。
3. 双击 `start.bat`，脚本会自动：
   - 检测 Java 环境
   - 启动后端服务（默认 `8080` 端口）
   - 8 秒后自动打开浏览器访问 <http://localhost:8080>

> 如需启用 AI，先按第 5 节配置环境变量，再运行脚本。

### 2.2 方式 B：源码构建（开发者）

```bash
# 1) 克隆代码
git clone https://github.com/abai54188/ai-diet-management-system.git
cd ai-diet-management-system

# 2) 构建前端（产物自动输出到 backend/src/main/resources/static）
cd frontend
npm install
npm run build
cd ..

# 3) 构建后端（生成 diet-backend-1.0.0.jar）
cd backend
mvn clean package
cd ..

# 4) 一键启动
start.bat
```

### 2.3 方式 C：开发模式（前后端分离，热更新）

```bash
# 终端 1 - 启动后端 (8080)
cd backend
mvn spring-boot:run

# 终端 2 - 启动前端 (5173)
cd frontend
npm install
npm run dev
```

浏览器访问 <http://localhost:5173>（前端已配置代理，将 `/api` 转发到 `8080`）。

## 4. 功能使用指南

### 4.1 健康档案
进入「健康档案」，填写身高、体重、**目标体重**、年龄、性别、活动量、健康目标、忌口/过敏源，点击保存。
> 这些数据会作为 AI 饮食建议与食谱生成的个性化上下文。

### 4.2 营养与食谱
1. 进入「营养与食谱」，搜索或按分类浏览食材；
2. 点击「添加」并在弹窗中设置**食材重量**，加入已选列表；
3. 已选列表实时汇总「热量 / 蛋白质 / 碳水 / 脂肪」；
4. 可**调节重量**（已选列表支持的重量列可直接改）或**删除**某项；
5. 点击右上角「用这些食材生成食谱」调用 AI 生成菜单。

### 4.3 拍照识菜 / AI 食谱生成
- **识菜**：上传食物图片，AI 识别食材成分并返回营养估算。
- **AI 食谱**：「食谱生成」页可基于已选食材与健康档案，生成多套菜单（含食材用量与详细做法）。

### 4.4 饮食打卡
1. 进入「饮食打卡」，选择餐次，添加食物（可选择食材，也支持 AI 整道菜打卡）；
2. 提交后系统统计当日摄入的热量与三大营养素；
3. AI 结合「健康档案 + 今日摄入 + 目标对比」生成个性化饮食建议（约 15~30 秒返回）。

### 4.5 体重管理 / 健康分析
- 「体重管理」：记录每日体重，查看趋势曲线与 BMI。
- 「健康分析」：查看营养摄入与体重变化的可视化图表。

### 4.6 营养助手
「营养助手」提供大模型对话式营养咨询服务，可自由提问饮食与营养问题。

### 4.7 社区广场
- 发布动态、点赞、评论、关注其他用户；
- 收藏与评分食谱；
- 社区动态支持敏感词过滤与内容举报。

### 4.8 数据看板 / 后台管理
- 「数据看板」：个人数据概览。
- 「后台管理」（仅管理员）：用户管理、内容管理、食材库管理、数据统计。

## 5. AI 大模型配置（可选）

系统通过环境变量读取 AI 配置，密钥不写入代码与仓库。**Windows** 下以用户级环境变量配置：

```powershell
[Environment]::SetEnvironmentVariable("AI_API_KEY","sk-你的密钥","User")
[Environment]::SetEnvironmentVariable("AI_BASE_URL","https://dashscope.aliyuncs.com/compatible-mode/v1","User")
[Environment]::SetEnvironmentVariable("AI_MODEL","qwen-plus","User")
```

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `AI_API_KEY` | 空 | 大模型密钥（必填） |
| `AI_BASE_URL` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | OpenAI 兼容接口地址 |
| `AI_MODEL` | `qwen-plus` | 文本模型名称 |
| `AI_VISION_MODEL` | `qwen-vl-plus` | 视觉模型名称（拍照识菜专用，需支持图片输入） |
| `AI_MOCK` | `false` | `true` 时关闭真实 AI，走本地规则兜底 |

> 配置完成后需**重新运行 `start.bat`**（或重启终端）使环境变量生效。

## 6. 常见问题（FAQ）

**Q1：双击 `start.bat` 提示找不到 Java？**
请安装 Java 17 并确保 `java -version` 能正常输出。下载：<https://adoptium.net/>。

**Q2：提示找不到 `diet-backend-1.0.0.jar`？**
该 jar 为构建产物，需先按「方式 B」执行 `mvn clean package` 生成，或将其放置到 `start.bat` 同目录。

**Q3：AI 功能报错 / 无返回？**
检查是否已配置 `AI_API_KEY`；确认网络可访问 `AI_BASE_URL`；生成的食谱/建议耗时较长（最长 180 秒），请耐心等待。

**Q4：前端刷新如 `/food/query` 出现 404？**
使用一体化部署（后端托管静态资源）时已做 SPA 兜底；如使用开发模式请通过 <http://localhost:5173> 访问。

**Q5：如何修改数据库/端口？**
- 端口与数据库路径见 `backend/src/main/resources/application.yml` 的 `server.port` 与 `spring.datasource.url`。
- 数据库文件默认生成于工作目录下的 `data/diet.db`（已入 `.gitignore`，运行时自动创建）。`start.bat` 运行时位于项目根目录 `data/diet.db`；使用 `mvn spring-boot:run` 或 IDE 启动时位于 `backend/data/diet.db`。

**Q6：`8080` 端口被占用？**
修改 `application.yml` 或命令 `java -jar diet-backend-1.0.0.jar --server.port=8081`。
