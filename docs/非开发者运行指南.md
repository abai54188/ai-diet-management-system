# AI 智能饮食管理系统 — 非开发者运行指南

> 面向**普通使用者**：你不需要会写代码、不需要装数据库，跟着下面几步就能在 Windows 电脑上跑起来。

---

## 一、你只需要准备一样东西

**Java 17** —— 系统运行所依赖的运行环境，装一次即可。

1. 打开 <https://adoptium.net/>
2. 点击 **Download**，根据你的系统选 **Windows x64**，下载安装包
3. 双击安装，一路「下一步」完成

> 装完后怎么确认成功？
> 按 `Win + R`，输入 `cmd` 回车，在弹出的黑窗口输入 `java -version` 回车，若显示 `java version "17..."` 即成功。

---

## 二、下载两个文件

| 文件 | 从哪里下载 |
| --- | --- |
| `diet-backend-1.0.0.jar` | 本仓库 **Releases** 页 → v1.0.0 → 下载附件 |
| `start.bat` | 本仓库根目录（点开文件后右上角「下载」/「Raw」另存） |

> 打开 Releases 页：仓库首页右侧 **Releases**（或点击 [这里](https://github.com/abai54188/ai-diet-management-system/releases)）。

把这两个文件放到**同一个文件夹**里，例如新建一个 `AI饮食管理系统` 文件夹放进 `D:\`。

---

## 三、双击启动

1. 进入放好文件的文件夹
2. **双击 `start.bat`**
3. 出现黑窗口，脚本会自动：
   - 检查 Java 环境
   - 启动服务（首次启动会自动建库、导入 1200+ 食材数据，稍等几秒）
   - 约 8 秒后**自动打开浏览器**进入系统首页

> 若浏览器没有自动打开，手动打开浏览器访问 <http://localhost:8080>

> ⚠️ 若要停止系统，直接**关闭黑窗口**（或按 `Ctrl + C`）即可。

## 五、（可选）启用 AI 功能

AI 相关的「拍照识菜 / AI 食谱 / 营养助手 / 饮食建议」需要配置大模型密钥。**没有密钥也不影响**营养查询、打卡、体重、社区等本地功能。

密钥**不需要改代码或任何文件**，而是配置到 Windows 的「环境变量」里，系统启动时自动读取。

**方法一：命令行一键配置（推荐，最省事）**

打开一个**新的** CMD 窗口，执行：

```bat
setx AI_API_KEY "sk-你的密钥"
```

> 记得把 `sk-你的密钥` 换成从 [阿里云百炼](https://bailian.console.aliyun.com/) 申请到的真实 API Key。

**方法二：图形界面配置**

1. 按 `Win` 键，搜索「环境变量」→ 打开「编辑系统环境变量」
2. 点「环境变量」→ 在**用户变量**里点「新建」
3. 变量名填 `AI_API_KEY`，变量值填真实密钥，点「确定」保存

无论用哪种方法，配置完成后都请 **关闭旧的 `start.bat` 窗口，重新双击 `start.bat`** 才会生效。

**可选变量（一般不用配，已有默认值）**

| 变量名 | 作用 | 默认值 |
| --- | --- | --- |
| `AI_API_KEY` | **必配**，大模型密钥 | 空 |
| `AI_BASE_URL` | 接口地址 | 阿里云百炼兼容端点 |
| `AI_MODEL` | 模型名 | `qwen-plus` |

**不配置会怎样？**

双击 `start.bat` 时会提示 `AI_API_KEY is not set. AI features will be disabled.`——即 **AI 相关功能（拍照识菜 / AI 食谱 / 营养助手 / 饮食建议）不可用，其余功能（登录、食材查询、饮食打卡、体重管理、健康档案、社区等）全部正常**。

## 六、常见问题

**Q1：双击后一闪而过 / 提示找不到 Java？**
说明 Java 没装或没装好，回到第一节重装 Java 17，装完重新双击 `start.bat`。

**Q2：提示「未找到可运行 jar 文件」？**
`start.bat` 和 `diet-backend-1.0.0.jar` 没有放在同一个文件夹，或文件名不对。把它们放到一起重试。

**Q3：浏览器打不开 / 一直转圈？**
- 确认黑窗口还开着（关闭窗口 = 停止服务）
- 手动访问 <http://localhost:8080>
- 若提示端口占用，说明 8080 被其他程序占用，请关闭占用程序后重试

**Q4：AI 功能一直没结果 / 报错？**
多半是没配置 `AI_API_KEY` 或网络不通。检查第五节配置，并确认能访问外网。

**Q5：数据会丢吗？**
所有数据保存在运行目录下的 `data/diet.db` 文件里，删除这个文件会清空数据。备份时复制整个文件夹即可。
